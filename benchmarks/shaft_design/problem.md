# Shaft preliminary diameter (STANDARD engineering)

## Problem statement

Определить **предварительный минимальный диаметр** стального круглого вала
для передачи **10 kW** при **1500 rpm** с заданным коэффициентом запаса.

Необходимо:

1. вычислить крутящий момент \( T = P / \omega \);
2. выбрать/зафиксировать модель материала (допустимое напряжение / предел
   текучести) — **не** утверждать единственно верную марку стали;
3. применить критерий прочности (например, \(\tau = 16T/(\pi d^3)\));
4. получить теоретический диаметр;
5. проверить единицы;
6. сделать sanity check;
7. провести независимую verification.

## Scope

Это **не** полное промышленное проектирование (шпонки, усталость, посадка
подшипников не требуются). Цель — проверить декомпозицию, assumptions,
deterministic calculation и verification.
